# Work4 文件快搜（work4-tools）

基于 C++17 + 原生 Win32 API 的绿色免安装文件快速搜索工具，界面类似 Windows 资源管理器。

## 特性
- 多线程全盘扫描建立本地二进制索引（索引位于 exe 同级 `index\` 目录）
- 扫描使用 Windows 默认调度策略（不绑定特定 CPU 核心），索引约 127 万条目 2-5 秒完成
- 索引就绪后内存多线程过滤，搜索毫秒级返回，结果上限 10 万条
- 首次运行无索引时自动后台构建，期间搜索自动降级为实时多线程扫描
- 资源管理器式界面：地址栏、目录树、文件列表（名称/大小/类型/修改时间排序）、
  搜索框（支持 `*`/`?` 通配符）、前进/后退/向上/刷新、右键菜单（打开/打开所在位置/复制路径）
- 单实例运行；双击文件用系统默认程序打开

## 构建
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
产物：`build\work4-tools.exe`（约 1.2MB，仅依赖系统 DLL）。
构建脚本还会在桌面创建"Work4 文件快搜"快捷方式。

## 使用
- 首次启动自动建立全盘索引（本地固定盘，跳过回收站/系统卷信息目录）
- 在搜索框输入关键词即搜（300ms 防抖），支持通配符
- 索引重建：工具栏"重建索引"按钮或菜单"查看 → 重建索引"
- 状态栏显示索引构建进度与搜索结果耗时

## 测试
```powershell
powershell -ExecutionPolicy Bypass -File tools\smoke-test.ps1
```
自动化验证：窗口/控件创建、目录浏览、全盘索引构建、关键词搜索。
